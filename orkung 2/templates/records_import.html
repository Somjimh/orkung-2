How it works

Import in this order: 1. Animals, then 2. Weights, then 3. Health observations, 4. Store count, 5. Treatments (these take medicine off the stock) and 6. Tasks / flags. The Health Forms workbook has an Observations sheet and a Treatments sheet: upload the same file in box 3 and box 5. You can upload a .csv file or the Excel filling sheet (.xlsx). Each file is checked first and nothing is saved until you press Commit. Animals already on the site, weights already recorded for that date, and tasks already pending are skipped, so importing the same file twice does not add anything twice. Tags are matched by species, and leading zeros are ignored ('039' = '39').
