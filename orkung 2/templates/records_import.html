How it works

Import in this order: 1. Animals, then 2. Weights, then 3. Tasks / flags. Each file is checked first and nothing is saved until you press Commit. Animals already on the site, weights already recorded for that date, and tasks already pending are skipped, so importing the same file twice does not add anything twice. Tags are matched by species, and leading zeros are ignored ('039' = '39').
